# Assignment 4: Graph, BFS and DFS

This repository contains C++ implementations of:
- Graph representation using adjacency list
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Cycle detection in undirected graph

Course: IIOT-2402 Algorithms and Data Structures  
Language: C++

## Files
- graph.cpp – graph representation
- bfs.cpp – BFS traversal and shortest path
- dfs.cpp – recursive and iterative DFS
- cycle_detection.cpp – cycle detection using DFS
- Assignment_4_Graph_BFS_DFS_Report.pdf – report
